# IFIT2-IFIT3 eCLIP Analysis Results

## Overview

This document presents the results of the IFIT2-IFIT3 eCLIP (enhanced CrossLinking and ImmunoPrecipitation) analysis pipeline. The analysis examines the RNA binding preferences of IFIT2 and IFIT3 proteins, both individually and as a complex, with a focus on 5' UTR (untranslated region) binding patterns.

---

## Figure 1: IFIT Binding Comparison

![IFIT Comparison](data/results/figures/ifit_comparison.pdf)

### Description

This 6-panel figure provides a comprehensive comparison of 5' UTR length distributions across different IFIT binding categories:

**Categories analyzed:**
- **Unbound** (gray): Transcripts not bound by either IFIT2 or IFIT3 (n = 86,205)
- **IFIT2 only** (blue): Transcripts bound exclusively by IFIT2 (n = 3,226)
- **IFIT3 only** (green): Transcripts bound exclusively by IFIT3 (n = 346)
- **Complex** (red): Transcripts bound by the IFIT2-IFIT3 complex (n = 2,629)

### Panel Descriptions

| Panel | Title | Description |
|-------|-------|-------------|
| **A** (top-left) | UTR Length Distribution by Binding Category | Density histograms showing the distribution of 5' UTR lengths for each binding category. X-axis limited to 0-500 nt for clarity. |
| **B** (top-center) | Cumulative Distributions | Empirical cumulative distribution functions (ECDFs) for each category. The dashed vertical line marks 50 nt, a biologically relevant threshold for "short" UTRs. |
| **C** (top-right) | UTR Length by Binding Category | Box plots comparing 5' UTR length distributions. Outliers excluded for visualization clarity. |
| **D** (bottom-left) | Short 5' UTR Enrichment | Bar chart showing the fraction of transcripts with short (<50 nt) 5' UTRs in each category. |
| **E** (bottom-center) | Transcript Counts | Bar chart displaying the total number of transcripts in each binding category. |
| **F** (bottom-right) | Median UTR Lengths | Bar chart comparing median 5' UTR lengths across categories. Dashed line indicates the 50 nt threshold. |

### Generation Method

Generated by `scripts/06_visualize.py` using the `plot_ifit_comparison()` function in `scripts/visualization.py`. Data derived from:
1. GENCODE v19 annotation (5' UTR coordinates)
2. CLIPper peak calls normalized against size-matched input
3. BEDTools intersections to identify bound transcripts

## Figure 2: 5' UTR Length Distribution (Complex Binding)

![UTR Length Histogram](data/results/figures/utr_length_histogram.pdf)

### Description

This 3-panel figure focuses specifically on the IFIT2-IFIT3 complex binding, comparing bound vs. unbound transcripts.

### Panel Descriptions

| Panel | Title | Description |
|-------|-------|-------------|
| **A** (left) | 5' UTR Length Distribution | Overlapping density histograms comparing bound (red) and unbound (gray) transcripts. |
| **B** (center) | Cumulative Distribution | ECDFs with a dashed line at 50 nt threshold. Shows the cumulative fraction of transcripts at each UTR length. |
| **C** (right) | 5' UTR Length Comparison | Box plots with Mann-Whitney U test p-value displayed (p = 1.00e+00). |

### Statistical Analysis

- **Test performed**: Mann-Whitney U test (one-sided, alternative='less')
- **Null hypothesis**: Bound transcripts have the same or longer 5' UTRs compared to unbound
- **P-value**: 1.00 (not significant)

### Generation Method

Generated by `scripts/06_visualize.py` using the `plot_utr_length_analysis()` function. Statistical test performed using `scipy.stats.mannwhitneyu()`.

## Key Observations

### 1. Transcript Binding Distribution

| Category | Count | Percentage of Bound |
|----------|-------|---------------------|
| IFIT2 only | 3,226 | 52.0% |
| Complex | 2,629 | 42.4% |
| IFIT3 only | 346 | 5.6% |
| **Total Bound** | **6,201** | 100% |

- IFIT2 binds substantially more transcripts independently than IFIT3
- A significant fraction (42.4%) of bound transcripts are bound by the IFIT2-IFIT3 complex
- IFIT3 alone shows the most restricted binding (only 346 transcripts)

### 2. 5' UTR Length Patterns

**Median 5' UTR Lengths (from Figure 1F):**
- Unbound: ~500 nt
- IFIT2 only: ~900 nt
- IFIT3 only: ~900 nt
- Complex: ~550 nt

**Observations:**
- Both IFIT2-only and IFIT3-only bound transcripts show longer median 5' UTRs compared to unbound transcripts
- Complex-bound transcripts have median UTR lengths closer to unbound transcripts
- The short 5' UTR enrichment (<50 nt) is minimal across all categories (Figure 1D)

### 3. Statistical Significance

The Mann-Whitney U test (p = 1.00) in Figure 2C indicates:
- **No significant enrichment** for shorter 5' UTRs in complex-bound transcripts
- This contradicts the hypothesis that IFIT proteins preferentially bind mRNAs with short 5' UTRs
- The bound transcripts actually show a trend toward longer UTRs

## Methods Summary

### Pipeline Overview

1. **Raw data processing**: FASTQ files from eCLIP experiments
2. **Alignment**: STAR aligner to hg19 reference genome
3. **Deduplication**: umi_tools to remove PCR duplicates
4. **Peak calling**: CLIPper (v2.0.0) via Singularity container (`brianyee/clipper:5d865bb`)
5. **Normalization**: Input-normalized peak significance using YeoLab Perl scripts
6. **UTR analysis**: Intersection with GENCODE v19 5' UTR annotations
7. **Visualization**: matplotlib/seaborn for publication-quality figures

### Samples Analyzed

| Sample | Description | Type |
|--------|-------------|------|
| IFIT2_IFIT3_FLAG_IP | Complex pulldown (FLAG-tagged IFIT2) | IP |
| IFIT2_IFIT3_HA_IP | Complex pulldown (HA-tagged IFIT3) | IP |
| IFIT2_alone_FLAG_IP | IFIT2 alone pulldown | IP |
| IFIT3_alone_HA_IP | IFIT3 alone pulldown | IP |
| WT_FLAG_IP | Wild-type FLAG control | Control |
| WT_HA_IP | Wild-type HA control | Control |

## Extended Analyses

Since the initial 5' UTR analysis showed no significant preference for short UTRs (p = 1.00), additional analyses were performed to explore alternative hypotheses about IFIT2-IFIT3 function.

### Extended Analysis 1: Genomic Distribution of Binding Sites

**Script**: `scripts/07_genomic_distribution.py`

**Objective**: Determine where IFIT binding occurs across different genomic features.

**Method**: HOMER `annotatePeaks.pl` annotates each peak with its genomic context.

**Output Files**:
- `data/results/genomic_distribution/annotated_peaks.txt` - Full HOMER annotations
- `data/results/genomic_distribution/distribution_summary.csv` - Summary statistics
- `data/results/figures/genomic_distribution_grouped.pdf` - Grouped bar plot
- `data/results/figures/genomic_distribution_stacked.pdf` - Stacked bar plot

**Feature Categories**:
| Feature | Description |
|---------|-------------|
| 5' UTR | 5' untranslated region |
| 3' UTR | 3' untranslated region |
| Exon (CDS) | Coding sequence exons |
| Intron | Intronic regions |
| Promoter/TSS | Transcription start site vicinity |
| TTS | Transcription termination site |
| Intergenic | Between genes |

---

### Extended Analysis 2: Metagene Binding Profiles

**Script**: `scripts/07b_metagene_profile.py`

**Objective**: Visualize binding density across normalized transcript regions.

**Method**: deepTools `computeMatrix` + `plotProfile` creates metagene profiles.

**Output Files**:
- `data/results/metagene/metagene_matrix.gz` - Computed matrix
- `data/results/figures/metagene_profile.pdf` - Line profile plot
- `data/results/figures/metagene_heatmap.pdf` - Heatmap visualization

**Interpretation**:
- Peaks near the 5' end suggest translation initiation involvement
- Peaks in CDS suggest translational regulation
- Peaks near the 3' end suggest mRNA stability regulation

---

### Extended Analysis 3: Functional Enrichment

**Script**: `scripts/08_functional_enrichment.py`

**Objective**: Identify biological processes and pathways enriched in IFIT-bound genes.

**Method**: g:Profiler API queries GO, KEGG, and Reactome databases.

**Output Files**:
- `data/results/enrichment/{category}_GO_BP.csv` - GO Biological Process terms
- `data/results/enrichment/{category}_GO_MF.csv` - GO Molecular Function terms
- `data/results/enrichment/{category}_KEGG.csv` - KEGG pathways
- `data/results/figures/{category}_GO_BP_dotplot.pdf` - Enrichment dotplots
- `data/results/figures/GO_BP_comparison_heatmap.pdf` - Cross-category comparison

**Key Questions Addressed**:
- Are IFIT-bound genes enriched for immune response pathways?
- Do different binding categories (IFIT2 vs IFIT3 vs complex) target different pathways?
- Is there enrichment for viral response or translation-related genes?

---

### Extended Analysis 4: Motif Discovery

**Script**: `scripts/09_motif_analysis.py`

**Objective**: Identify RNA sequence motifs enriched in IFIT binding sites.

**Method**:
1. Extract sequences from peak regions using `bedtools getfasta`
2. Run MEME Suite STREME for de novo motif discovery
3. K-mer frequency analysis as Python-native fallback

**Output Files**:
- `data/results/motifs/{sample}_peaks.fa` - Peak sequences (DNA)
- `data/results/motifs/{sample}_peaks_rna.fa` - Peak sequences (RNA)
- `data/results/motifs/{sample}_streme/` - STREME output (if MEME installed)
- `data/results/motifs/{sample}_6mer_frequencies.csv` - K-mer counts
- `data/results/motifs/gc_content_summary.csv` - GC content analysis
- `data/results/figures/kmer_comparison_heatmap.pdf` - K-mer comparison
- `data/results/figures/gc_content_distribution.pdf` - GC distribution

**Key Questions Addressed**:
- Do IFIT proteins recognize specific RNA sequences?
- Are there differences in motif preferences between IFIT2 and IFIT3?
- Is GC content or specific sequence composition associated with binding?

## Conclusions

### Initial Analysis
1. **IFIT2 shows broader RNA binding** compared to IFIT3 when expressed alone
2. **The IFIT2-IFIT3 complex** binds a distinct subset of transcripts (2,629 targets)
3. **No enrichment for short 5' UTRs** was observed in IFIT-bound transcripts
4. **IFIT-bound transcripts tend to have longer 5' UTRs** than unbound transcripts
